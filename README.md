# 1st_Project
1st project / Semantic and adaptive layout / HTML + CSS
1ый проект / Семантический и адаптивный макет / HTML + CSS

## Адаптивная вёрстка макета
Этот проект представляет собой вёрстку макета с использованием HTML и CSS. Проект адаптивен и корректно отображается на различных устройствах.

## Демонстрация
Проект доступен по ссылке: [GitHub Pages](https://futtur1stt.github.io/1st_Project/)

## Установка
Чтобы запустить проект локально, выполните следующие шаги:

1. Клонируйте репозиторий:
   git clone https://github.com/polyakgg777/adaptive-layout.git
2. Перейдите в директорию проекта:
   cd 1st_Project
3. Откройте файл index.html в своем браузере

## Структура проекта:
1st_Project/
├── index.html # Основной HTML файл
├── style.css # Основной файл стилей
├── FandN.css # Файл для нормализации стилей и подключения шрифтов
└── Images/ # Папка с изображениями
└── Icons/ # Папка с иконками
└── Fonts/ # Папка с файлами шрифтов
