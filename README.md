# 1st_Project
1st project / Semantic and adaptive layout / HTML + CSS</br>
1ый проект / Семантический и адаптивный макет / HTML + CSS</br>

## Адаптивная вёрстка макета
Этот проект представляет собой вёрстку макета с использованием HTML и CSS.</br>
Проект адаптивен и корректно отображается на различных устройствах.</br>

## Демонстрация
Проект доступен по ссылке: [GitHub Pages](https://futtur1stt.github.io/1st_Project/)

## Установка
Чтобы запустить проект локально, выполните следующие шаги:

1. Клонируйте репозиторий:
   git clone https://github.com/Futtur1stt/1st_Project.git
2. Перейдите в директорию проекта:
   cd 1st_Project
3. Откройте файл index.html в своем браузере

## Структура проекта:
1st_Project/</br>
├── index.html # Основной HTML файл</br>
├── style.css # Основной файл стилей</br>
├── FandN.css # Файл для нормализации стилей и подключения шрифтов</br>
└── Images/ # Папка с изображениями</br>
└── Icons/ # Папка с иконками</br>
└── Fonts/ # Папка с файлами шрифтов</br>
